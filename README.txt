QUASAR MINING - ONE CLICK
==============================

1. Extract this zip to any folder (example: Desktop\QuasarMiner)
2. Double-click:  Start-Quasar-Mining.vbs
3. Press the big gold button:  START MINING

That's it. No typing. No black window. No Python needed -
if Python is missing, the app downloads and installs it
automatically (one time only).

WHAT HAPPENS BEHIND THE SCENES (automatic):
  - Python check / silent install
  - Mining components installed
  - Your wallet created (first time only)
  - Miner starts hidden in the background
  - Every ~30 seconds a new block -> coins go to YOUR wallet

THE WINDOW SHOWS LIVE:
  - Current block number (growing = mining works)
  - Your wallet balance in QSR

TO STOP: press STOP in the window, or just close it.
Your coins stay saved - nothing is lost.

YOUR EXISTING CHAIN: if you already mined before, copy your
old "quasar-seed" folder next to Start-Quasar-Mining.vbs -
the app will find it and continue where you stopped.

This is TESTNET/DEMO software. Coins have no money value.
