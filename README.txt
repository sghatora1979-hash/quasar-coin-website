QUASAR MINING - One-Click Miner (v2)
====================================

HOW TO START (one time only):
  1. Extract this zip anywhere (e.g. Downloads).
  2. Double-click START-MINING.bat
  3. Press the gold START MINING button.

That's it. Python installs itself on first run. The seed
address is already filled in - the miner joins the Quasar
network automatically.

AFTER THAT - never open this folder again:
  * Tick "Start mining automatically with Windows" and the
    miner resumes on its own after every reboot.
  * Or open your Quasar website dashboard - the "My Miner"
    card shows live Block + Balance with START / STOP buttons
    that control this laptop's miner from the browser.

YOUR COINS:
  Mined coins go to this laptop's wallet, stored in the
  quasar-seed folder next to this file. Stopping the miner
  never deletes coins.

TROUBLESHOOTING:
  * Windows SmartScreen / antivirus warning: this is normal
    for new mining software - choose "Run anyway" / restore
    from quarantine. The miner only connects to the Quasar
    seed and mines test coins; it sends nothing anywhere else.
  * If the seed laptop's WiFi address changes, edit seed.txt
    (one line: IP:port).
