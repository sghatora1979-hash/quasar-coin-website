⬇️ Download One-Click Miner

📖 Prefer step-by-step? The full 6-step guide is right below.

● LIVE NETWORK Block — — miners online — QSR minted

01

⬇️ Install Python

  1. Go to python.org → Downloads → Windows → download the latest Python 3.x.
  2. Run the installer → tick ✅ "Add python.exe to PATH" (do NOT skip this!) → Install Now.
  3. Check it: open cmd, type python --version and press Enter.

👀 You will see:

Python 3.12.1
⚠️ If you see 'python' is not recognized — you missed the PATH tick. Reinstall Python with the tick.
02

📦 Download the miner

  1. Click the button below and save the zip file.
  2. Right-click the zip → Extract All → Extract.

👀 You will see:

a folder with files like quasar_cli.py, node.py, README.md ⬇️ Download Miner
03

👛 Create your wallet (one time only)

  1. Open cmd INSIDE the extracted folder (click the address bar, type cmd, press Enter).
  2. Type: set QUASAR_DATA_DIR=quasar-seed and press Enter. No output = OK.
  3. Type: python quasar_cli.py new-address miner and press Enter.

👀 You will see:

Your address: QU... saved to quasar-seed\wallets\miner.json
🔑 This address is your wallet. Never share the wallet file — anyone with it can take your coins. (You can use any name instead of "miner".)
04

🖥️ Start the node

  1. In the same cmd window, type:
    python quasar_cli.py start-node --port 9333 --datadir quasar-seed
  2. If Windows Firewall asks → click Allow access.

👀 You will see:

Starting P2P node on port 9333 (data: quasar-seed)... quasar-node:9333>
⚠️ This is the node window. Do NOT close it (minimize is fine). Closing it stops everything.
05

⚡ Start mining

  1. In the node window (quasar-node:9333>) type: mine-auto miner and press Enter.

👀 You will see:

Mining block 1 (difficulty=000, 0 txs)... Block #1 mined! ...

Your laptop now mines on its own — about one block every ~30 seconds. Press Ctrl+C to stop.

06

💰 Check your coins

  1. In the node window type: balance miner and press Enter.

👀 You will see:

Balance: 50000.0 QSR

Every block adds 50,000 QSR. 🎉

🛠️ Stuck somewhere? Common fixes

'python' not recognizedPATH tick was missed → reinstall Python with ✅ "Add python.exe to PATH".
'mine' not recognizedYou're in normal cmd. Type it in the node window (quasar-node:9333>).
Wallets: (none yet)You opened a new cmd window → run the set line again in it.
No such fileFolder name mismatch → use the same datadir name in every command.
Firewall popupClick Allow access — the node needs port 9333.
Laptop getting hotKeep it on a hard table (not bed/sofa), charger plugged in.

❓ FAQ

Frequently asked questions

What is halving?

Halving means the mining reward gets cut in half. Quasar pays a flat 50,000 QSR per block for the first ~5.7 years (300B coins). Then it halves to 25,000 for 2.5 years, then 12,500 for 2.5 years — then mining stops. Early miners earn more; late joiners earn less. That's the deal, written in code.

When will it come to an exchange?

When millions use it and real demand exists, exchanges will list it themselves. First the network, then demand, then listing.

How will the coin get value?

Value is born the day someone first trades something real for the coin. An exchange doesn't create price — it only displays it. People create price when they trade.

Is this real money?

No! This is a testnet — practice coins. They are worth nothing. If anyone asks you for money in their name, it's a scam.

Will my laptop overheat?

Keep it on a hard table (not on the bed), plugged in. If it gets too hot the laptop protects itself — it won't catch fire. 😊

Can I mine from my phone?

Not yet — real mining happens with the laptop program. A mobile app is coming in phase 3.
